Filament Sanchaya

A Filament-native file manager and media picker for Laravel — filling a gap in the FilamentPHP ecosystem. Sanchaya (सञ्चय) means "gathering something valuable" in Nepali.

↗
$ composer require dp0/filament-sanchaya
PHP 8.4 Laravel 13 Filament 5 Livewire
✓ Full-featured file manager with folder tree navigation
✓ Multi-disk support with cursor-based pagination
✓ Cross-disk move & copy with on-the-fly ZIP streaming
✓ Reusable MediaPicker field with polymorphic attachments
✓ Authorization via Laravel Gates with swappable policy
✓ Independently configurable, replaceable action classes
